HoverPrompt 2.5.2

设置 / Settings

本地 API 不受云端月额度限制。同步由你主动发起，不上传个人 API 密钥。 / Personal API is independent of cloud quota. Sync is manual; API keys stay local.

提示词语言版本 / Prompt languages

从上到下为展示和快捷复制优先级，第一种可用语言默认展示。勾选项控制生成语言。 / Order controls display and quick-copy priority; the first available language is the default. Checkboxes control generation.

每次可生成 1–12 种语言；自定义名称与代码，不改变界面语言。 / Generate 1–12 versions independently of UI language.

历史提示词展示 / History prompt display

历史图片快捷复制始终使用第一种可用的优先语言。 / The image quick-copy button always copies the first available preferred language.

原图和网页显示尺寸均需达到门槛；同时应用于提示词按钮和批量采集，手动上传不受影响。 / Both source and displayed dimensions must meet the threshold. Applies to image buttons and batch collection; manual uploads are unaffected.

API 来源与路由 / Sources & Routing

备用路由仅在网络错误、超时、404、429、5xx 时切换，图片会发往下一个启用的来源。401/403、参数错误不会切换。每个来源指定一个模型；优先级模式从数字最小的来源开始。 / Failover uses the next enabled source on network errors, timeouts, 404, 429 or 5xx. Authentication and parameter errors stop the request. Each source has one selected model; priority mode starts from the lowest number.

并行与请求控制 / Request control

同时排队的反推任务最多 4 张合成一次请求，指令只发一次；某张结果缺失或格式不对时单独重发这一张。仅对个人 API 和本地模型生效。 / Up to 4 queued analyses share one request, so the instructions are sent once; an image whose result is missing or malformed is re-sent on its own. Applies to personal APIs and local models.

并发数控制当前悬浮窗内的任务；请求按频率均匀发送，排队时间不算超时。超时重试使用同一来源，次数达到上限后停止。路由的其他失败切换仍按来源配置执行。 / Concurrency applies to tasks in the current floating window. Requests are spread evenly by rate; queue time does not count toward the timeout. Timeout retries use the same source and stop at the limit. Other failures follow the source routing.

尚未配置 / Not configured

OpenAI、Anthropic 通常填写带 /v1 的基础地址；Gemini 原生填写 https://generativelanguage.googleapis.com/v1beta。中转站按其文档填写。密钥只保存在本浏览器。 / Use the provider base URL, usually ending in /v1 for OpenAI or Anthropic. Native Gemini uses https://generativelanguage.googleapis.com/v1beta. For relays, follow their docs. API keys stay in this browser.
